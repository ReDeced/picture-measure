## Запуск

Из исходников:

```bash
cargo run --release
```

Из собранного бинарника:

```bash
picture-measure                       # пустое окно
picture-measure photo.png             # сразу открыть картинку
picture-measure photo.png out.json    # картинка и готовая разметка
picture-measure --help
```

Требуется Rust 1.85 или новее. Системных библиотек доустанавливать не нужно:
приложение собрано на `winit` + OpenGL и работает на Windows, macOS, Linux
(X11 и Wayland).

## Открытие картинки

Три способа, все равнозначные:

1. **Перетащить файл в окно.** Поддерживаются PNG, JPEG, WebP и BMP.
2. **Вписать путь** в поле «Путь» на боковой панели и нажать **Открыть**.
3. **Передать путь аргументом командной строки.**

Кнопка **Вставить** рядом с полем пути берёт путь из буфера обмена — удобно,
если путь был скопирован из файлового менеджера или терминала.

При открытии новой картинки текущая разметка очищается. Чтобы не потерять
работать, сначала сохранитесь.

## Инструменты

Переключаются кнопками на панели сверху или клавишами.

| Инструмент | Клавиша | Что делает |
|---|---|---|
| **Рисование** | <kbd>D</kbd> | Клик — точка, протяжка — прямоугольник, <kbd>Shift</kbd> — квадрат |
| **Выбор** | <kbd>V</kbd> | Клик — выделить, протяжка — переместить |
| **Удаление** | <kbd>X</kbd> | Клик по фигуре — удалить её |
| **Панорама** | <kbd>H</kbd> | Протяжка — двигать картинку |

### Рисование

- **Клик** (нажатие и отпускание почти в одной точке) ставит **точку** в
  координатах пикселя, где был клик.
- **Протяжка** рисует **прямоугольник** от точки нажатия до текущей позиции.
  Прямоугольник всегда нормализован: если тянуть вверх-влево, он всё равно
  получится с положительными размерами, просто начнётся в левом верхнем углу.
- **<kbd>Shift</kbd> + протяжка** рисует **квадрат**. Длина стороны равна
  большему из двух смещений, а квадрат растёт в ту сторону, куда движется
  курсор.
- Во время протяжки сверху показывается предпросмотр с размерами.

Порог «клик или протяжка» — 4 экранных пикселя. Дрожание руки при клике не
превращается в крошечный прямоугольник.

### Выбор

- Клик по фигуре выделяет только её.
- Клик по пустому месту снимает выделение.
- <kbd>Shift</kbd> + клик добавляет фигуру к выделению или убирает из него.
- Протяжка за выделенную фигуру двигает её.
- <kbd>Ctrl</kbd>+<kbd>A</kbd> выделяет всё.

### Удаление

Клик по фигуре удаляет её сразу (с записью в историю, поэтому
<kbd>Ctrl</kbd>+<kbd>Z</kbd> вернёт). Либо выделите фигуры и нажмите
<kbd>Delete</kbd> — то же самое.

### Контекстное меню

Правый клик по фигуре открывает меню: **Выбрать**, **Дублировать**,
**Вернуть имя по умолчанию**, **Удалить**. Правый клик по пустому месту ничего
не делает, чтобы не мешать панорамированию.

| Клавиши | Действие |
|---|---|

| <kbd>ЛКМ</kbd> протяжка | прямоугольник |
| <kbd>Shift</kbd>+<kbd>ЛКМ</kbd> протяжка | квадрат |
| <kbd>СКМ</kbd> / <kbd>ПКМ</kbd> протяжка | панорама |
| <kbd>Alt</kbd>+<kbd>ЛКМ</kbd> | панорама |
| колесо мыши | масштаб |
| <kbd>D</kbd> <kbd>V</kbd> <kbd>X</kbd> <kbd>H</kbd> | инструменты |
| <kbd>F</kbd> | вписать картинку |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | сохранить JSON |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | копировать JSON в буфер |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | отменить |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Y</kbd> | повторить |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | выбрать всё |
| <kbd>Esc</kbd> | снять выделение и прервать рисование |
| <kbd>Delete</kbd> / <kbd>Backspace</kbd> | удалить выделенные фигуры |

Тот же список открывается кнопкой **Горячие клавиши** на боковой панели.

## Вид и масштаб

- **Колесо мыши** — масштаб вокруг позиции курсора: точка под курсором не
  «уезжает».
- **Протяжка** средней или правой кнопкой, либо <kbd>Alt</kbd>+<kbd>ЛКМ</kbd> —
  панорама.
- **Вписать** (<kbd>F</kbd>) — показать картинку целиком с небольшим отступом.
- **100%** — один экранный пиксель на один пиксель картинки.
- Слева от кнопок показано текущее увеличение в процентах.

Три переключателя внизу панели «Экспорт»:

- **Подписи** — имя фигуры рядом с ней.
- **Сетка** — координатная сетка с «круглыми» шагами (1, 2, 5 × 10ⁿ), которые
  меняются вместе с масштабом.
- **Линейки** — горизонтальная и вертикальная линии, идущие за курсором.

В строке состояния внизу всегда видны координаты курсора в пикселях картинки.

## Имена и подпапки

По умолчанию каждая фигура называется `point_N` или `rect_N`, где `N` —
сквозной номер. Номера не переиспользуются после удаления, так что имена всегда
уникальны.

Чтобы задать своё имя:

1. Выберите фигуру (инструментом «Выбор» или кликом по списку слева).
2. В поле **Имя** введите текст. В списке он появится со звёздочкой `*` —
   это значит «пользовательское имя».
3. Кнопка **Сбросить** возвращает авто-имя.

Кнопка **Перенумеровать** делает номера снова подряд: `point_1`, `rect_2`,
`point_3`… Пользовательские имена при этом не трогаются.

### Подпапки

Поле **Подпапка** в разделе «Новые фигуры» задаёт папку, которая автоматически
проставится всем новым фигурам. Достаточно выбрать её один раз и забыть.

Уже созданную фигуру можно переложить в другую папку:

- поле **Папка** в разделе «Свойства выбранного»;
- или выделить несколько фигур и вписать папку в разделе «Свойства», где
  показано «Выбрано фигур: N», затем нажать `→`.

Подпапка может быть вложенной: `faces/eyes/left`. Разделители приводятся к `/`.

## Правка фигур

Кроме рисования доступно:

| Действие | Как |
|---|---|
| Переместить | Инструмент «Выбор», тянуть за фигуру |
| Дублировать | Кнопка **Дублировать** или контекстное меню |
| Перекрасить | Палитра в разделе «Свойства» |
| Удалить | <kbd>Delete</kbd>, инструмент «Удаление» или **✕** в списке |
| Отменить любое действие | <kbd>Ctrl</kbd>+<kbd>Z</kbd> |

История хранит последние 128 состояний, включая переименование, перекрашивание и
перемещение.

## Сохранение и загрузка

### Сохранить

**Сохранить JSON** (<kbd>Ctrl</kbd>+<kbd>S</kbd>) пишет файл по пути из поля
«Путь JSON». При открытии картинки путь подставляется автоматически:
`photo.png` → `photo.json`. Можно поменять вручную.

**Копировать JSON** (<kbd>Ctrl</kbd>+<kbd>C</kbd>) кладёт тот же текст в буфер
обмена — удобно для отправки результата в чат.

Пока есть несохранённые изменения, в правом верхнем углу горит
**● есть изменения**.

### Загрузить

- **Перетащите `.json` в окно.**
- Либо передайте путь вторым аргументом: `picture-measure photo.png out.json`.
- Кнопка **Открыть** в поле «Путь» понимает и `.json`: если в пути расширение
  `json`, загружается разметка, иначе — картинка.

При загрузке разметки программа попробует открыть картинку, путь к которой
записан в поле `image.path`. Если файла уже нет, разметка всё равно загрузится.

Число знаков после запятой регулируется ползунком (0…4). При `0` координаты
пишутся целыми числами.

## Раздельный экспорт

Кнопка **Записать** в блоке «Папка для раздельного экспорта» создаёт дерево
файлов, по одному на фигуру, раскладывая их по подпапкам:

```
out/
├── eyes/
│   ├── left_eye.json
│   └── right_eye.json
└── rect_3.json
```

Каждый файл — полноценный документ с одной фигурой. Небезопасные символы в
именах заменяются, совпадающие имена получают суффикс `_2`, `_3`. Подробности в
[JSON_FORMAT.md](JSON_FORMAT.md#раздельный-экспорт).

## Подсказки и подсветка

- Подсвеченная фигура рисуется жёлтым с уголками — так видно, что выбрана.
- Размер прямоугольника показан по центру, если он достаточно большой.
- Имя и подпапка показаны рядом с фигурой, если включены «Подписи».
- В списке слева наведение показывает полное описание: имя, тип и координаты.
- «Свойства выбранного» показывает точные координаты и размер фигуры.

## Частые вопросы

**Почему квадрат не того размера, что я ожидал?**
Длина стороны берётся по большему из двух смещений. Если тянуть почти
горизонтально, сторона будет равна горизонтальному смещению.

**Координаты зависят от масштаба?**
Нет. В JSON всегда пиксели исходной картинки.

**Почему после удаления имена идут не подряд?**
Номера фигур не переиспользуются, чтобы имена оставались уникальными. Нажмите
**Перенумеровать**, если нужна сплошная нумерация.

**Что будет, если отпустить кнопку мыши вне окна?**
Жест прервётся, ничего лишнего не создастся.

**Можно ли рисовать на очень большой картинке?**
Да. Координаты хранятся как `f32`, этого достаточно для изображений до
~16 миллионов пикселей по стороне.

**Программа поддерживает многоугольники, линии, полилинии?**
Пока нет. Формат JSON расширяемый, но текущая версия умеет только точки и
прямоугольники — см. [issues](https://github.com/ReDeced/picture-measure/issues).
